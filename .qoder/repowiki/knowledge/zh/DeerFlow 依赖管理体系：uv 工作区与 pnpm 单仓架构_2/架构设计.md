- **后端分层**：采用 `backend/app/gateway` 作为 FastAPI 入口，通过中间件链（Auth, CSRF, CORS）处理安全边界；业务逻辑下沉至 `packages/harness/deerflow` 核心包，实现 Agent 引擎与 API 层的解耦。
- **前端架构**：基于 Next.js App Router 构建，通过 `frontend/src/core/api` 封装统一的 Fetch 客户端，自动处理 CSRF Token 注入与身份认证状态同步。
- **扩展机制**：引入 `deerflow_extensions` 模块，通过启动引导器（Boot Loader）在应用生命周期初期动态挂载 ADS 认证、数据采集等插件，实现零侵入式功能增强。
- **依赖管理**：后端使用 `uv` Workspaces 模式管理 `deer-flow` 与 `deerflow-harness` 的本地依赖关系；前端锁定 `pnpm` 确保依赖树一致性。
