- 后端路由定义遵循模块化原则，每个功能域（如 threads, agents, mcp）在 `app/gateway/routers` 下拥有独立的 router 文件并统一注册到主应用。
- 前端 API 调用强制使用 `frontend/src/core/api/fetcher.ts` 中的封装方法，以确保所有状态变更请求自动携带 CSRF Token 且包含用户凭证。
- 后端中间件采用 Fail-Closed 策略，除明确定义的公共路径（如 /health, /login）外，所有请求必须通过身份验证中间件校验。
- 项目根目录的 Makefile 作为统一的操作界面，屏蔽了底层 Python/Node 脚本的差异，提供了跨平台（Windows/macOS/Linux）兼容的开发指令。
