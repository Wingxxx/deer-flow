- **分层架构设计**：采用 `src/core`（领域逻辑/Hooks）、`src/components`（UI 表现）、`src/app`（路由/布局）的分层模式，确保业务逻辑与视图分离。
- **零侵入扩展机制**：在 `extensions/` 目录下定义独立模块（如认证、环境配置），通过注册表模式（Registry Pattern）向核心组件（如 `SettingsDialog`、`InputBox`）注入 UI 与逻辑，实现核心源码的零修改扩展。
- **统一鉴权与网关代理**：通过 `middleware.ts` 与服务端 `getServerSideUser` 实现 SSR 阶段的身份守卫；客户端通过封装的 `fetch` 自动处理 CSRF Token 与 Cookie 凭证，统一对接后端网关。
- **多语言与主题协同**：在根布局 `layout.tsx` 中统一包裹 `I18nProvider` 与 `ThemeProvider`，结合自定义 Hook 实现全应用范围内的国际化与深色模式同步。
