- **分层结构**：模块分为 `api/`（生产代理层）和 `mock/api/`（演示数据层）。
- **代理机制**：`api/memory` 下的路由通过 `fetch` 将请求透明转发至 `NEXT_PUBLIC_BACKEND_BASE_URL` 指定的后端服务，并处理 Header 清洗。
- **Mock 实现**：`mock/api` 下的路由直接返回硬编码的 JSON 配置（如 MCP 服务器、LLM 模型列表），或通过 Node.js `fs` 模块读取 `public/demo/threads` 目录下的文件系统数据来模拟线程历史记录与资源检索。
- **路由规范**：遵循 Next.js App Router 约定，利用动态路由段（`[thread_id]`）和捕获组（`[...path]`）处理复杂路径映射。
