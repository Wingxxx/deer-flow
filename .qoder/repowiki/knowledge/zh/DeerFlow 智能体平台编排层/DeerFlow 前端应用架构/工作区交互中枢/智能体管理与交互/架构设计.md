- **路由层**：采用 Next.js App Router，包含列表页 (`page.tsx`)、新建向导页 (`new/page.tsx`) 和聊天详情页 (`[agent_name]/chats/[thread_id]/page.tsx`)。
- **组件层**：`AgentGallery` 与 `AgentCard` 负责展示；新建页集成 `PromptInput` 实现“对话即配置”的引导流程；聊天页复用 `ChatBox`、`MessageList` 等核心工作区组件。
- **数据层**：通过 `@/core/agents` 模块封装 API 调用（如 `checkAgentName`, `getAgentWithRetry`），处理智能体元数据的 CRUD 及名称唯一性校验。
- **状态管理**：利用 React Context (`ThreadContext`, `ArtifactsProvider`) 在聊天会话中共享线程状态与产物信息。
