- 采用分层测试架构：`e2e/` 目录存放基于 Playwright 的端到端测试，通过 `mock-api.ts` 拦截并模拟 LangGraph 及后端 API 响应；`unit/` 目录存放基于 Vitest 的单元测试，针对 `core/`、`components/` 等模块进行逻辑验证。
- 包含混合集成测试：`e2e-real-backend/` 目录下的测试连接真实后端网关，利用回放模型（replay model）验证前端在真实数据流下的渲染行为。
- 共享工具支持：E2E 测试共用 `utils/mock-api.ts` 提供的确定性 Mock 数据生成器，确保测试环境的稳定性与可重复性。
