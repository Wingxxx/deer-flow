- **架构模式**：采用零侵入扩展架构，各子模块独立于核心源码，通过注册表（Registry）或中间件注入方式对接。
- **ads_auth**：基于 Next.js Middleware 实现路由重写与 `ads_token` 会话校验，包含自定义登录页组件。
- **env-settings**：通过 `registerSettingsExtension` 注册设置面板，利用 TanStack Query 管理状态，经由 REST API 与后端交互。
- **input-suggestions**：定义全局注册表 API (`registerInputSuggestion`)，支持动态添加带图标和分组的建议项。
- **mobile-sidebar**：提供响应式浮动触发器，根据设备类型与侧栏状态控制显示逻辑。
