- **Skills**: `api.ts` 定义后端交互，`hooks.ts` 封装 React Query (`useQuery`, `useMutation`)，`type.ts` 定义数据模型。
- **Tasks**: `types.ts` 定义 `Subtask` 接口，`context.tsx` 通过 React Context 管理子任务状态并提供 `useUpdateSubtask` 钩子，`subtask-result.ts` 解析后端返回的任务结果字符串。
- **Messages**: `usage-model.ts` 和 `usage.ts` 处理 Token 用量统计与调试视图构建，`utils.ts` 负责消息分组（如 `getMessageGroups`）、内容提取及内部标记清理。
