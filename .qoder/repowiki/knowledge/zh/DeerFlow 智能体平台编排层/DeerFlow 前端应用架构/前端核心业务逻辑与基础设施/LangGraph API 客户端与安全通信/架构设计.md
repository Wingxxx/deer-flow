- **核心入口**：`api-client.ts` 导出 `getAPIClient`，负责创建并缓存 `LangGraphClient` 实例。
- **安全层**：`fetcher.ts` 实现 `fetchWithAuth` 包装器，统一处理 `credentials: include` 及状态变更请求的 `X-CSRF-Token` 注入；`api-client.ts` 通过 `onRequest` 钩子将相同逻辑同步至 SDK 调用。
- **流式处理**：`stream-mode.ts` 提供 `sanitizeRunStreamOptions`，在请求发出前过滤不支持的 LangGraph 流模式并给出警告。
- **环境适配**：根据 `static-mode` 配置自动切换至 `createStaticClient`，拦截 SDK 方法以返回本地静态演示数据。
- **业务接口**：`feedback.ts` 基于安全 `fetch` 封装用户反馈的增删接口。
