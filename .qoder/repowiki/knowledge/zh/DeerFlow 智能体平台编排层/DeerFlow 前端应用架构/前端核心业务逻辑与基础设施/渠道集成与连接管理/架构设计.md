- **分层结构**：模块采用清晰的四层架构。`types.ts` 定义核心数据模型；`api.ts` 封装后端 RESTful 交互；`provider-state.ts` 提供纯函数逻辑以判断提供商状态；`hooks.ts` 基于 React Query 暴露声明式数据获取与变更接口。
- **连接流程协同**：`open-connect-url.ts` 处理 OAuth 授权窗口的开启与安全隔离，`connect-poll.ts` 实现连接状态的后台轮询，两者配合完成异步绑定流程。
- **依赖方向**：内部工具层（poll/url）无外部依赖，API 层依赖全局 fetcher，Hooks 层聚合 API 与状态管理，形成自底向上的单向依赖。
