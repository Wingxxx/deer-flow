- **分层结构**：模块分为 `settings`（核心逻辑）和 `settings-extensions`（扩展机制）两个子包。
- **存储层 (`local.ts`)**：封装 `localStorage` 读写，定义 `LocalSettings` 接口（含通知、Token 用量、上下文模型等），处理 SSR 兼容性（`isBrowser`）及默认值合并。
- **状态管理层 (`store.ts`)**：实现轻量级发布订阅模式，维护全局设置快照及会话级模型名称映射，通过 `storage` 事件监听实现跨标签页同步。
- **交互层 (`hooks.ts`)**：提供 `useLocalSettings`（全局）和 `useThreadSettings`（会话级覆盖）两个 React Hooks，利用 `useSyncExternalStore` 桥接外部存储状态。
- **扩展机制 (`settings-extensions/`)**：通过内存数组 `_extensions` 和注册函数 `registerSettingsExtension`，允许外部动态注入设置面板 UI 组件（含图标、标签及 React 组件）。
