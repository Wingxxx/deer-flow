- **入口层**：`index.ts` 仅导出 `loader` 模块，作为外部访问的统一接口。
- **逻辑层**：`loader.ts` 封装核心加载逻辑，区分远程文件获取（通过 `utils.ts` 构建 URL）与本地工具调用草稿提取（依赖 `preview.ts`）。
- **状态层**：`hooks.ts` 基于 `@tanstack/react-query` 提供 `useArtifactContent`，处理缓存、加载状态及 `write-file:` 协议的特殊路由。
- **工具层**：`preview.ts` 负责解析 `write_file` 工具调用的历史消息以重建草稿，并提供 HTML 预览的 `<base>` 标签注入与滚动位置恢复脚本生成；`utils.ts` 处理不同环境（静态演示/模拟/生产）下的 API 路径构造。
