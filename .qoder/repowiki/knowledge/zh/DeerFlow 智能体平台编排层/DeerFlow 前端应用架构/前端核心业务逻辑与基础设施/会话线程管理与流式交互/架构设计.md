- **核心层**：`types.ts` 定义 `AgentThread`、`AgentThreadState` 等核心数据结构，作为模块内部统一的数据契约。
- **逻辑层**：`hooks.ts` 是模块的核心实现，封装了 `useThreadStream`（流式交互）、`useThreadHistory`（历史分页加载）以及基于 React Query 的 CRUD Hooks（搜索、删除、重命名）。
- **接口层**：`api.ts` 负责与后端进行非流式 API 通信（如 Token 用量统计），`export.ts` 提供 Markdown/JSON 格式的会话导出逻辑。
- **工具层**：`utils.ts` 和 `token-usage.ts` 提供路由生成、消息文本提取及用量数据转换等纯函数支持。
- **依赖方向**：所有逻辑均围绕 `@langchain/langgraph-sdk` 的客户端实例展开，通过 `getAPIClient` 获取底层连接能力。
