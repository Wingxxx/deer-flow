- **统一通信层**：所有子模块（如 agents, threads, models）均依赖 `core/api` 提供的 LangGraph SDK 封装客户端，该客户端统一处理 CSRF 注入、静态演示模式降级及流式请求错误恢复。
- **全局状态编排**：通过 `AuthProvider`、`I18nProvider` 和 `SubtaskContext` 等 React Context 在应用顶层注入跨模块共享状态（用户身份、语言环境、任务进度），确保 UI 响应的一致性。
- **配置与环境隔离**：`core/config` 集中管理后端与 LangGraph 服务的基地址，结合 `static-mode` 实现生产环境与静态演示环境的无缝切换，各业务模块通过此配置动态初始化客户端。
- **标准化数据获取模式**：各功能域（agents, memory, skills 等）严格遵循“API 封装 + TanStack Query Hooks”的组合模式，实现数据缓存、后台刷新及加载状态的统一管理。
