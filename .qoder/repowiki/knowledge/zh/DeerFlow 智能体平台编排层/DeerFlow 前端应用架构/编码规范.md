- 核心业务逻辑封装在 `src/core` 目录下，以 `api.ts`（数据获取）、`hooks.ts`（状态订阅）、`types.ts`（类型定义）为标准文件结构。
- 扩展模块通过 `registerXxx` 函数向全局注册表注入配置，核心组件通过 `getXxx()` 读取并渲染，禁止在核心代码中硬编码扩展逻辑。
- API 请求统一使用 `src/core/api/fetcher.ts` 提供的 `fetch` 包装器，自动携带 `credentials: include` 及 CSRF 防护头。
- 服务端组件（SSR）通过 `src/core/auth/server.ts` 的 `getServerSideUser` 获取初始用户状态，避免客户端 hydration 时的闪烁。
