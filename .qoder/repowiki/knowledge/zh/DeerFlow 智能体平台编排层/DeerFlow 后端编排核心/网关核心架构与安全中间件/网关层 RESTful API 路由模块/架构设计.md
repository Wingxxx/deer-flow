- **模块化路由设计**：采用按业务域拆分的文件结构（如 `auth.py`, `threads.py`, `agents.py`），每个文件内部实例化独立的 `fastapi.APIRouter` 并通过 `prefix` 和 `tags` 进行逻辑分组。
- **依赖注入与中间件集成**：通过 `Depends` 机制集成身份验证（如 `get_current_user_from_request`）和权限控制（如 `@require_permission` 装饰器），实现横切关注点的解耦。
- **标准化响应模型**：广泛使用 `pydantic.BaseModel` 定义请求体和响应体，确保接口契约的强类型约束与自动文档生成。
- **入口聚合**：通过 `__init__.py` 显式导出各子模块路由，便于上层应用统一注册与管理。
