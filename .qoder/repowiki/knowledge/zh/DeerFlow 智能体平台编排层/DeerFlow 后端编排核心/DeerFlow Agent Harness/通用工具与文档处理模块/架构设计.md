- **模块化设计**：按职责拆分为 `file_conversion`（文档转换）、`network`（网络资源管理）、`readability`（网页解析）和 `time`（时间处理）四个独立单元。
- **异步适配策略**：在 `file_conversion.py` 中通过 `asyncio.to_thread` 将耗时的同步 I/O 操作（如 PDF 解析）卸载至线程池，避免阻塞事件循环。
- **容错与回退机制**：PDF 转换采用“pymupdf4llm 优先 + MarkItDown 兜底”的双引擎策略；网页提取在 `readability.py` 中实现 JS 引擎失败后自动降级为纯 Python 解析。
- **并发安全原语**：`network.py` 封装了基于锁（Lock）的 `PortAllocator`，确保多线程环境下端口分配的原子性与资源自动释放。
