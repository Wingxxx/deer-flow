- **入口与缓存层**：`__init__.py` 导出核心 API，`cache.py` 提供基于配置文件修改时间的懒加载与失效机制。
- **客户端配置层**：`client.py` 负责将扩展配置转换为 `langchain-mcp-adapters` 所需的服务器参数（支持 stdio/sse/http）。
- **安全与拦截层**：`oauth.py` 实现 OAuth Token 的获取、缓存与自动刷新，并构建工具调用拦截器以注入认证头。
- **会话管理层**：`session_pool.py` 维护按 `(server_name, scope_key)` 隔离的 LRU 持久化会话池，解决无状态调用导致的上下文丢失问题。
- **工具加载层**：`tools.py` 协调 `MultiServerMCPClient` 初始化，集成 OAuth 拦截器与自定义拦截器，并提供同步/异步兼容的工具包装器。
