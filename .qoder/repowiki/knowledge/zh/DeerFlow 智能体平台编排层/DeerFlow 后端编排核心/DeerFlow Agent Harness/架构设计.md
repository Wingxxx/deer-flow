- **双模态执行架构**：提供同步嵌入式客户端（`DeerFlowClient`）与异步网关工作流，前者直接调用 `agent.stream()` 实现进程内交互，后者通过 `StreamBridge` 桥接 LangGraph 事件至 SSE 协议。
- **声明式中间件装配**：利用 `RuntimeFeatures` 驱动 `create_deerflow_agent` 工厂，按固定顺序（如 Sandbox → Guardrail → Memory）自动组装中间件链，支持通过 `@Next/@Prev` 锚点动态插入自定义逻辑。
- **运行时上下文注入**：在 `RunnableConfig` 中显式注入 `ToolRuntime` 与 `AppConfig`，确保工具与中间件在无全局状态依赖的情况下获取线程级元数据与应用配置。
- **状态持久化与回滚**：集成 `BaseCheckpointSaver` 实现多轮对话状态管理，并在异常或用户中断时支持基于预运行快照的原子级状态回滚。
