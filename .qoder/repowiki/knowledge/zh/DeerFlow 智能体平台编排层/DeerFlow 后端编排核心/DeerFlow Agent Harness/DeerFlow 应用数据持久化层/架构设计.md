- **核心架构**：采用 `engine.py` 统一管理异步引擎生命周期，支持 Memory、SQLite（开启 WAL 模式）和 PostgreSQL 三种后端，并提供开发环境下的自动建表能力。
- **模型设计**：所有 ORM 模型继承自 `base.py` 定义的 `Base` 类，通过缓存的反射机制提供通用的 `to_dict()` 序列化方法，避免重复编写转换逻辑。
- **子域划分**：按业务实体划分为 `run`（运行记录）、`thread_meta`（会话元数据）、`channel_connections`（IM 渠道连接与 OAuth 状态）、`feedback`（用户反馈）等独立子包，每个子包包含模型定义与 SQL 逻辑。
- **迁移管理**：集成 Alembic (`migrations/`) 处理 schema 演进，明确限定其仅管理 DeerFlow 自有表结构，不干涉 LangGraph 的检查点表。
- **跨库兼容**：通过 `json_compat.py` 实现自定义 `JsonMatch` 表达式编译器，屏蔽 SQLite 与 PostgreSQL 在 JSON 类型查询上的语法差异，确保过滤逻辑的一致性。
