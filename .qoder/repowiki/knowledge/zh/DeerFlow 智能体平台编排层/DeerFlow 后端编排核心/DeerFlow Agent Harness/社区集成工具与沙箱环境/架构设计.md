- 沙箱子模块 (`aio_sandbox`)：采用策略模式，通过 `SandboxBackend` 抽象基类解耦本地容器 (`LocalContainerBackend`) 与远程K8s (`RemoteSandboxBackend`) 实现；`AioSandboxProvider` 负责线程安全的资源池化、空闲回收及跨进程文件锁协调。
- 工具子模块 (如 `brave`, `tavily`, `jina_ai`)：遵循统一结构，每个提供商独立目录，通过 `tools.py` 暴露 `@tool` 装饰的 LangChain 工具函数；复杂逻辑封装于同目录下的 Client 类中。
- 配置集成：所有工具均通过 `get_app_config().get_tool_config()` 动态读取 API Key 及运行时参数，支持环境变量回退。
