- **入口与工厂模式**：`__init__.py` 导出 `create_chat_model`，由 `factory.py` 根据配置动态解析并实例化 LangChain `BaseChatModel` 子类。
- **凭证抽象层**：`credential_loader.py` 封装了 Claude Code 和 Codex CLI 的 OAuth/Token 加载逻辑，支持环境变量、文件描述符及本地 JSON 文件的自动发现。
- **提供商适配体系**：通过继承 LangChain 基础类（如 `ChatOpenAI`, `ChatAnthropic`）实现特定模型的补丁逻辑。包括 `claude_provider` (OAuth Bearer 认证与缓存控制)、`openai_codex_provider` (Responses API 流式处理)、`mindie_provider` (XML 工具调用解析) 以及 `vllm_provider` (推理字段保留)。
- **通用重放机制**：`assistant_payload_replay.py` 提供了在多云轮对话中恢复 `reasoning_content` 或 `thought_signature` 等易丢失字段的通用工具，被 `patched_deepseek`, `patched_openai` 等模块复用。
