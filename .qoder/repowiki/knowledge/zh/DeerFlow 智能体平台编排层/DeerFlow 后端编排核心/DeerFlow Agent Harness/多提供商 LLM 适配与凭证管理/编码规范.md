- 所有自定义模型类均继承自 LangChain 的基础聊天模型类，并通过重写 `_get_request_payload` 或 `_generate` 方法注入特定于提供商的逻辑。
- 敏感凭证加载逻辑统一收敛至 `credential_loader.py`，模型初始化时通过 `model_post_init` 钩子自动调用加载器并设置私有属性（如 `_access_token`）。
- 针对多轮对话中容易丢失的提供商特定字段（如推理内容、签名），采用“捕获原始消息 -> 序列化后比对 -> 重新注入 payload”的重放模式。
- 模型实例化后，若检测到追踪回调配置，会自动将 `build_tracing_callbacks()` 生成的回调列表附加到模型实例的 `callbacks` 属性中。
