- **统一发现与动态装配**：以 `get_available_tools` 为核心入口，根据 `AppConfig` 聚合配置化工具、内置协作工具（如澄清、任务委派）、MCP 扩展工具及 ACP 代理工具。
- **安全与能力感知过滤**：在加载阶段执行多重过滤，包括基于 `LocalSandboxProvider` 的 Host Bash 禁用检查、基于模型配置的 Vision 工具注入，以及基于 `tool_search` 配置的 MCP 工具延迟注册。
- **跨环境运行时适配**：利用 `sync.py` 中的线程池与上下文变量复制机制，为纯异步 LangChain 工具提供同步调用包装器，确保在同步 Agent 路径下的稳定执行。
- **标准化元数据契约**：通过 `mcp_metadata.py` 定义统一的 `deerflow_mcp` 标记接口，实现工具来源的跨模块识别，支撑延迟工具注册表（DeferredToolRegistry）对 MCP 工具的精准分类与管理。
- **冲突消解与去重**：实施严格的工具名去重逻辑，优先保留配置加载的工具，防止因内置工具与 MCP/配置工具同名导致的 LLM 调用歧义。
