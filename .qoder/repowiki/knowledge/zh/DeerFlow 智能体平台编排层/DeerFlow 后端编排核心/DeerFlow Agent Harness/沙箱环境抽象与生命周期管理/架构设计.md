- **抽象契约**：`sandbox.py` 定义了 `Sandbox` 抽象基类，规范了命令执行、文件读写及内容搜索等核心能力；`sandbox_provider.py` 定义了 `SandboxProvider` 负责沙箱实例的生命周期管理（acquire/release）。
- **策略注入**：通过 `get_sandbox_provider()` 单例工厂，结合配置系统动态解析并实例化具体的 Provider 实现（如 `LocalSandboxProvider`），实现了核心逻辑与底层实现的解耦。
- **中间件编排**：`middleware.py` 实现了 `SandboxMiddleware`，作为 LangGraph Agent 的生命周期钩子。它根据 `thread_id` 自动在 `before_agent` 阶段获取沙箱，在 `after_agent` 阶段释放资源，并支持懒加载优化。
- **安全边界**：`security.py` 与 `tools.py` 共同构建了安全层，针对本地沙箱提供路径遍历防护、虚拟路径映射及宿主 Bash 执行的权限门控，确保不同实现下的安全一致性。
