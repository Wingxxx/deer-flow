- **分层架构**：模块采用清晰的职责分离设计。`types.py` 定义核心数据模型（`Skill`, `SkillCategory`）；`parser.py` 和 `validation.py` 负责 SKILL.md 文件的 YAML 元数据解析与校验；`installer.py` 处理 ZIP 归档的安全解压与原子化安装；`security_scanner.py` 集成 LLM 进行内容安全审查；`storage/` 子包通过抽象基类 `SkillStorage` 和具体实现 `LocalSkillStorage` 封装文件系统操作与历史记录管理。
- **接口边界**：`__init__.py` 暴露了 `Skill` 模型、`SkillStorage` 接口及工厂函数 `get_or_new_skill_storage`，作为外部调用的主要入口。
- **依赖方向**：核心逻辑（解析、安装、存储）不依赖 Web 框架，仅依赖基础库和配置模块。安全扫描器依赖 `deerflow.models` 进行 LLM 调用，体现了业务逻辑与 AI 能力的解耦。
