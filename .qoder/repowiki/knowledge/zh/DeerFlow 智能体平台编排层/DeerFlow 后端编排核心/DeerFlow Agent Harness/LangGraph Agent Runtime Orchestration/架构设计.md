- **统一运行时上下文 (RunContext)**：在 `runs/worker.py` 中组装 `checkpointer`、`store` 和 `event_store`，并通过 `langgraph.runtime.Runtime` 注入到 Agent 执行环境中，实现基础设施依赖的统一传递。
- **回调驱动的事件捕获**：利用 `journal.py` 中的 `RunJournal`（继承自 `BaseCallbackHandler`）拦截 LangChain/LangGraph 的生命周期回调，将 LLM 调用、Token 消耗及中间件行为标准化为运行事件并写入 `events/store`。
- **生产者-消费者解耦**：通过 `stream_bridge` 抽象层隔离后台执行任务（Producer）与 SSE 端点（Consumer），支持内存缓冲、心跳保活及断点重传，确保流式输出的稳定性。
- **带重试机制的状态同步**：`runs/manager.py` 维护内存中的运行注册表，并通过带有指数退避的重试策略将状态变更异步同步至持久化存储，以应对 SQLite 等后端的瞬时锁竞争。
