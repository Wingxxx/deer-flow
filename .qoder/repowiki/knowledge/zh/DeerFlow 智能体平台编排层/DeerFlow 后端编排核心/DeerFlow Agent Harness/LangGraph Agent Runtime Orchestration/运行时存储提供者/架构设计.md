- **接口层**：`__init__.py` 统一导出 `make_store`（异步）和 `get_store`/`store_context`（同步）。
- **实现层**：`async_provider.py` 负责异步上下文管理，`provider.py` 负责同步单例及上下文管理。
- **工具层**：`_sqlite_utils.py` 处理 SQLite 连接字符串解析及目录创建。
- **依赖方向**：模块依赖 `langgraph.store.base.BaseStore` 作为抽象基类，并根据 `config.yaml` 中的 `checkpointer` 配置动态加载具体实现（InMemory, Sqlite, Postgres）。
