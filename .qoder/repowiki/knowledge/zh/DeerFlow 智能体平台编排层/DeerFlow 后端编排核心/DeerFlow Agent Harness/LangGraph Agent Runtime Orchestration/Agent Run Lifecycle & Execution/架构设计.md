- **核心管理层**：`manager.py` 定义了 `RunManager`，采用内存注册表（In-memory Registry）与可选的 `RunStore` 持久化后端相结合的架构。所有状态变更均通过 `asyncio.Lock` 保护，并内置了针对 SQLite 等后端的指数退避重试机制。
- **存储抽象层**：`store/` 子包定义了 `RunStore` 抽象基类（`base.py`），并提供了 `MemoryRunStore`（`memory.py`）作为默认实现，支持运行时动态切换存储后端。
- **执行工作流**：`worker.py` 实现了 `run_agent` 入口，负责在后台 `asyncio.Task` 中驱动 LangGraph 引擎，处理流式事件发布、检查点回滚（Rollback）及 Token 统计。
- **数据模型**：`schemas.py` 定义了标准化的运行状态（如 `pending`, `running`, `success`）和断开连接处理策略。
