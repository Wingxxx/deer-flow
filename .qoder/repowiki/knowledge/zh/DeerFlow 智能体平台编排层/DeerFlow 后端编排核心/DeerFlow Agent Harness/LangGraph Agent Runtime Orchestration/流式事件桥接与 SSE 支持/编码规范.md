- 所有桥接实现类必须继承 `base.StreamBridge` 并完整实现 `publish`、`subscribe`、`cleanup` 等抽象方法。
- 使用 `HEARTBEAT_SENTINEL` 和 `END_SENTINEL` 特殊事件对象作为流控制信号，而非直接关闭连接或抛出异常。
- 订阅接口 `subscribe` 统一返回 `AsyncIterator[StreamEvent]`，以适配 FastAPI 等框架的 SSE 响应流。
- 资源释放遵循异步上下文管理器规范，在 `finally` 块或 `close` 方法中清理 `_streams` 和 `_counters` 状态。
