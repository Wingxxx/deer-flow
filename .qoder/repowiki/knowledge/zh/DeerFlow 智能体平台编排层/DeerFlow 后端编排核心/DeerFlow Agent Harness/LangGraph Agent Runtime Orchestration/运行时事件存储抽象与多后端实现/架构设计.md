- 核心抽象：`store/base.py` 定义 `RunEventStore` 抽象基类，规范了事件写入（`put`, `put_batch`）、查询（`list_messages`, `list_events`）及删除等异步接口。
- 工厂模式：`store/__init__.py` 提供 `make_run_event_store` 工厂函数，根据配置动态实例化 `MemoryRunEventStore`、`DbRunEventStore` 或 `JsonlRunEventStore`。
- 多态实现：`memory.py` 基于字典实现轻量级存储；`db.py` 集成 SQLAlchemy 异步会话并处理 PostgreSQL/SQLite 兼容性；`jsonl.py` 采用文件系统存储并利用 `asyncio.to_thread` 避免阻塞事件循环。
- 模块出口：`__init__.py` 导出基础接口与默认内存实现，供上层运行时直接引用。
