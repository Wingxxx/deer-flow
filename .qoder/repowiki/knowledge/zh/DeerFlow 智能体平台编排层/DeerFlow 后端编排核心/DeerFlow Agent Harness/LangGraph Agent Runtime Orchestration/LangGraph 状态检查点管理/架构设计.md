- **双模态架构**：模块划分为 `provider.py`（同步单例/上下文管理器）和 `async_provider.py`（异步上下文管理器），分别服务于 CLI/脚本工具和 FastAPI 等长运行服务。
- **后端抽象**：通过 `CheckpointerConfig` 统一配置，动态加载 `InMemorySaver`、`SqliteSaver` 或 `PostgresSaver`，并处理依赖缺失时的 `ImportError`。
- **配置优先级**：在异步工厂中实现了从旧版 `checkpointer` 配置到新版统一 `database` 配置的兼容逻辑。
- **资源管理**：采用 Context Manager 模式确保数据库连接或连接池在退出作用域时正确关闭，同步模块额外提供了全局单例缓存机制。
