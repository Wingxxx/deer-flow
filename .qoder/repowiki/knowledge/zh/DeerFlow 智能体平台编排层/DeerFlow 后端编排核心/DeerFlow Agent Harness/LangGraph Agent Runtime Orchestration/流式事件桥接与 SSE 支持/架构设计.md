- 采用生产者-消费者架构：`base.py` 定义 `StreamBridge` 抽象协议及 `StreamEvent` 数据模型，明确发布（publish）与订阅（subscribe）边界。
- 实现层位于 `memory.py`，利用 `asyncio.Condition` 和环形缓冲区逻辑实现进程内事件存储，支持通过 `Last-Event-ID` 进行历史事件回放。
- 工厂模式封装在 `async_provider.py`，通过 `make_stream_bridge` 异步上下文管理器根据配置动态实例化桥接器，目前仅支持内存模式，预留 Redis 扩展接口。
- 配置管理由 `stream_bridge_config.py` 负责，使用 Pydantic 模型定义队列大小等参数，并通过全局状态注入运行时环境。
