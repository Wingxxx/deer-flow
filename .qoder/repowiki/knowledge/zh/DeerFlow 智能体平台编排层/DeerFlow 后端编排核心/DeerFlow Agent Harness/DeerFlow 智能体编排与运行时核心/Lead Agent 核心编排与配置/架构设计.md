- **核心工厂模式**：`agent.py` 中的 `make_lead_agent` 是主要入口，根据运行时配置（如 `is_plan_mode`、`subagent_enabled`）动态组装 LangChain Agent。
- **中间件流水线**：采用分层中间件架构，包括澄清（Clarification）、记忆（Memory）、摘要（Summarization）、待办事项（Todo）和子代理限制（SubagentLimit）等，通过 `_build_middlewares` 按特定顺序注入。
- **动态提示词工程**：`prompt.py` 实现了复杂的提示词模板系统，支持基于技能（Skills）、子代理能力、内存上下文和延迟工具（Deferred Tools）的动态内容注入，并包含缓存机制以优化性能。
- **声明式特性配置**：`factory.py` 和 `features.py` 提供了 `create_deerflow_agent` SDK 接口，允许通过 `RuntimeFeatures` 数据类声明式地启用或替换中间件，支持 `@Next`/`@Prev` 锚点定位。
- **状态管理**：依赖 `thread_state.py` 定义的 `ThreadState` 作为 Agent 的状态 schema，管理沙盒、线程数据、待办事项和查看过的图像等上下文。
