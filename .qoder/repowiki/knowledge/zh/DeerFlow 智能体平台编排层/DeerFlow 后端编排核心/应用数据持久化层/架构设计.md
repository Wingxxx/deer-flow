- **核心架构**：采用 `engine.py` 统一管理异步数据库引擎生命周期，支持 SQLite/PostgreSQL/Memory 多后端切换；`base.py` 定义带有自动序列化能力的 `Base` 类。
- **模块化设计**：按业务实体划分为 `run`、`thread_meta`、`feedback`、`user` 等子包，每个子包遵循“模型定义 (`model.py`) + SQL 仓储实现 (`sql.py`)”的垂直切片结构。
- **迁移管理**：集成 Alembic (`migrations/`) 处理 schema 演进，配置为仅管理 DeerFlow 自有表，避免干扰 LangGraph 内部状态表。
- **兼容性适配**：通过 `json_compat.py` 实现跨数据库（SQLite/PostgreSQL）的 JSON 字段类型安全查询与过滤逻辑。
