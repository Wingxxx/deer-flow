- **入口点**：`setup_wizard.py` 作为配置总控，`doctor.py` 和 `check.py` 负责环境与配置的健康诊断。
- **向导子系统 (`wizard/`)**：采用分步架构，通过 `steps/` 目录下的模块（LLM、搜索、执行模式）处理用户输入，由 `providers.py` 定义提供商元数据，`ui.py` 封装终端交互逻辑，`writer.py` 负责将配置持久化为 `config.yaml` 和 `.env`。
- **健康检查子系统**：`doctor.py` 实现了模块化的检查器（如 `check_python`, `check_llm_auth`），对 Python 环境、Node.js 依赖、API 密钥有效性及沙箱配置进行深度诊断。
- **辅助脚本群**：包含一系列 Shell 脚本（如 `build-release.sh`, `deploy.sh`）用于构建、部署及容器管理，以及 Python 静态分析脚本（如 `detect_blocking_io_static.py`）用于代码质量监控。
