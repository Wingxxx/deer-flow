- **统一引导层**：`boot.py` 作为核心入口，负责解析项目根路径并按序初始化各子模块，支持 PyInstaller 打包环境的早期补丁应用。
- **模块化扩展结构**：包含 `ads_auth`（ADS 认证）、`data_collection`（旁路数据采集）、`env_settings`（多厂商 API Key 管理）和 `topic_guardrail`（L1-L4 纵深防御）四个独立子包。
- **注入机制**：采用 `try/except ImportError` 包裹的软依赖设计，通过 `startup.py` 执行 FastAPI 路由注册或针对 `deerflow.agents` 内部函数的 Monkey Patch（如 `_build_middlewares`）。
- **补丁管理中心**：`patch_manager.py` 集中处理话题护栏相关的底层逻辑替换，包括敏感词中间件注入、不可变约束植入及角色定义动态重载，确保在应用生命周期早期生效。
