- 多环境配置隔离：提供 `nginx.conf`（Docker 容器内使用，依赖内部 DNS 解析服务名）、`nginx.local.conf`（本地开发使用，指向 localhost）和 `server.conf`（独立服务器部署片段）三种配置形态。
- 路径-based 路由策略：所有 `/api/*` 请求默认转发至 Gateway 服务（端口 8001），其中 `/api/langgraph/*` 通过 rewrite 规则兼容 LangGraph API 格式；其余请求转发至 Frontend 服务（端口 3001）。
- 流式传输优化：针对 SSE/Streaming 场景，全局禁用 `proxy_buffering` 和 `proxy_cache`，并设置长超时时间（600s）以支持长连接。
- 上游服务发现：在 Docker 环境中利用 `resolver 127.0.0.11` 实现动态服务名解析，避免容器重启后 IP 变更导致的连接失败。
