- **多环境分层**：通过 `docker-compose.yaml`（生产）和 `docker-compose-dev.yaml`（开发）实现环境隔离，利用 `nginx/nginx.conf` 统一流量入口。
- **服务拓扑**：Nginx 作为反向代理监听 2026 端口，将 `/api/*` 路由至 FastAPI Gateway，其余请求转发至 Next.js Frontend；Provisioner 服务负责 Kubernetes 沙箱生命周期管理。
- **扩展机制**：采用覆盖文件模式（如 `docker-compose.cli-auth.yaml`）按需挂载敏感目录（Claude/Codex CLI 配置），遵循最小权限与安全隔离原则。
- **依赖管理**：Gateway 依赖 `.env` 环境变量注入配置路径与认证令牌，并通过 `host.docker.internal` 与宿主机 Docker 守护进程或 K8s API 交互。
