- **环境依赖**：宿主机必须运行 Kubernetes 集群（如 Docker Desktop K8s、OrbStack），且 `~/.kube/config` 需正确挂载至容器内 `/root/.kube/config`。
- **网络配置**：若 K8s API Server 地址为本地回环，需设置 `K8S_API_SERVER=https://host.docker.internal:<port>`；后端访问沙箱需通过 `NODE_HOST`（默认为 `host.docker.internal`）解析 NodePort。
- **启动命令**：通常通过 `docker compose -f docker/docker-compose-dev.yaml up -d provisioner` 随开发栈启动。
