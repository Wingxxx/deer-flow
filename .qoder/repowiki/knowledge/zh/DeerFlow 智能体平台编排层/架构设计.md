- **统一流量入口**：Nginx 作为唯一对外端口（2026），基于路径前缀将 `/api/*` 代理至 Backend Gateway，其余请求转发至 Frontend Next.js 服务，实现前后端同源部署。
- **零侵入扩展总线**：Backend 在启动阶段通过 `deerflow_extensions.boot` 动态加载认证、数据采集等插件，利用 Monkey Patch 和路由注入在不修改核心代码的前提下增强功能。
- **跨域认证协同**：Frontend 中间件与 Backend Auth 插件共享 ADS Cookie 校验逻辑；Nginx 负责处理 CORS 头并隐藏上游重复响应，确保嵌入 ADS 环境时的会话一致性。
- **配置驱动编排**：根目录 `config.yaml` 统一定义模型、沙箱及护栏策略，Backend 启动时加载并同步至 LangGraph 运行时，Frontend 通过 API 获取运行时配置以动态调整 UI 行为。
