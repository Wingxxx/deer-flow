# 前端品牌自定义配置指南

## 概述

品牌自定义模块通过零侵入扩展机制，允许在不修改 DeerFlow 核心源码的前提下替换前端品牌标识。

### 替换项一览

| 位置 | 文件 | 替换字段 | 默认值 |
|------|------|---------|--------|
| 侧栏品牌名(折叠) | `workspace-header.tsx` | `appAbbreviation` | `"DF"` |
| 侧栏品牌名(展开) | `workspace-header.tsx` | `appName` | `"DeerFlow"` |
| 欢迎页问候语 | `welcome.tsx` | `welcome.greeting` | i18n 默认 |
| 欢迎页描述 | `welcome.tsx` | `welcome.description` | i18n 默认 |
| 页面标题 | `layout.tsx`（generateMetadata） | `appName` | `"DeerFlow"` |
| ADS 登录页品牌标题 | `extensions/ads_auth/LoginPage.tsx` | `loginPage.title` | `"ADS 账号登录"` |

### 设置页限制

设置弹窗只开放三个页面：
1. **账号**（Account）— `id: "account"`
2. **API Keys** — 由 `env-settings` 扩展注册的 `id: "api"`
3. **渠道配置** — 由 `env-settings` 扩展注册的 `id: "channels"`

其余内置页面（appearance, notification, memory, tools, skills, about）已通过 `hiddenSectionIds` 隐藏。

## 配置方法

### 架构层级

```
site.config.json (public/)     ← 运行时配置文件
       ↓
BrandingProvider               ← React Context，应用启动时加载
       ↓
workspace-header.tsx           ← 消费端 useBranding()
welcome.tsx                    ← useI18n() + useBranding() 叠加
ads_auth/LoginPage.tsx         ← useBranding()
layout.tsx (title)             ← 服务端读取 + 注入
```

### 扩展文件（`frontend/extensions/branding/`）

```
frontend/extensions/branding/
├── types.ts          # BrandingConfig 接口
├── config.ts         # 加载器（fetch /site.config.json）
├── context.tsx        # BrandingProvider + useBranding hook
└── README.md         # 扩展说明
```

#### types.ts — 配置接口

所有字段可选，缺失时自然降级到 i18n 默认值：

```typescript
export interface BrandingConfig {
  appName?: string;
  appAbbreviation?: string;
  welcome?: {
    greeting?: string;
    description?: string;
  };
  loginPage?: {
    title?: string;
  };
}
```

#### config.ts — 运行时加载器

```typescript
import type { BrandingConfig } from "./types";

let _cached: BrandingConfig | null = null;

export async function loadBrandingConfig(): Promise<BrandingConfig> {
  if (_cached) return _cached;
  try {
    const res = await fetch("/site.config.json", { cache: "no-store" });
    if (!res.ok) return {};
    _cached = await res.json();
    return _cached!;
  } catch {
    return {};
  }
}

export function clearBrandingCache(): void {
  _cached = null;
}
```

- 运行时 fetch，无需构建时注入
- 含 `_cached` 缓存避免重复请求
- 网络/解析失败返回空对象，不影响应用运行

#### context.tsx — Provider + Hook

```typescript
"use client";
import { createContext, useContext, useEffect, useState } from "react";
import type { BrandingConfig } from "./types";
import { loadBrandingConfig } from "./config";

const EMPTY_CONFIG: BrandingConfig = {};

const BrandingContext = createContext<BrandingConfig>(EMPTY_CONFIG);

export function BrandingProvider({ children }: { children: React.ReactNode }) {
  const [config, setConfig] = useState<BrandingConfig>(EMPTY_CONFIG);

  useEffect(() => {
    loadBrandingConfig().then(setConfig);
  }, []);

  return (
    <BrandingContext.Provider value={config}>
      {children}
    </BrandingContext.Provider>
  );
}

export function useBranding(): BrandingConfig {
  return useContext(BrandingContext);
}
```

- 服务端渲染时返回空对象，客户端 mount 后加载配置
- `useBranding()` 可在 Provider 外安全使用（返回空对象）

### 配置文件（`frontend/public/site.config.json`）

```json
{
  "appName": "ADS集智智能客服",
  "appAbbreviation": "ADS",
  "welcome": {
    "greeting": "欢迎回来",
    "description": "欢迎使用 ADS 集智智能客服平台..."
  },
  "loginPage": {
    "title": "ADS集智智能客服"
  }
}
```

- `public/` 目录 → Next.js 自动作为静态资源提供服务
- 修改后 **不需要重新构建**，刷新页面即生效
- 缺失字段时自动降级到 i18n 默认值或硬编码回退值

### 设置页限制配置

在 `workspace-nav-menu.tsx` 中已配置 `hiddenSectionIds`：

```typescript
const hiddenSectionIds = [
  "appearance",
  "notification",
  "memory",
  "tools",
  "skills",
  "about",
];
```

只保留内置的 `account` 和扩展注册的 `api` + `channels`。

| **风险** | ✅ 低 |


```diff

-  title: "DeerFlow",
-  ...

+  try {
+    const configPath = join(process.cwd(), "public", "site.config.json");

+    return {};
+  }
```
