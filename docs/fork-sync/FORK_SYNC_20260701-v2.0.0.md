## 经验教训

1. **锁文件自动合并可能丢失依赖**：commit `20e3daaa` 的 `pnpm-lock.yaml` 自动合并成功，但实际缺失 `@rsbuild/plugin-react` 条目，导致前端 TypeScript 类型检查失败。教训：锁文件即使自动合并无冲突，也必须在构建验证前运行 `pnpm install` / `uv lock`。

2. **零冲突 ≠ 零验证**：虽然 14 个提交无一触及侵入点，但构建验证（Task 3B.2）和全栈测试（Task 4）仍然发现了锁文件问题，证明了多层验证的必要性。

3. **snapshot 脚本的 `|| echo 0` 副作用**：grep -c 在无匹配时返回 exit code 1 但 stdout 仍为 "0"，加上 `|| echo 0` 会导致重复输出。已修正为去掉 `|| echo 0`。
