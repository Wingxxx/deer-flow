## Project Overview

**DeerFlowApp** — A minimal uni-app (Vue 3) shell that wraps a DeerFlow server in a full-screen WebView and packages it as an iOS/Android app via HBuilderX cloud build. No business logic, no native plugins, no third-party SDK dependencies.

## Development Workflow

This project is **HBuilderX-based** (not CLI-based). There are no `package.json`, `npm`, or CLI build scripts.

### Prerequisites
- HBuilderX (App development edition) — download from https://www.dcloud.io/hbuilderx.html
- Android: Developer mode + USB debugging enabled on phone
- iOS (optional): Apple Developer account ($99/year)

### Running on Device
1. Open `DeerFlowApp/DeerFlowApp` folder in HBuilderX
2. Connect phone via USB
3. Click `Run → Run to Phone or Simulator → Android/iOS`

### Building for Distribution
- **Android**: HBuilderX → `Publish → Native App Cloud Build` → Android (.apk)
  - Package name: `com.deerflow.app`
  - Certificate: DCloud default certificate
- **iOS**: HBuilderX → `Publish → Native App Cloud Build` → iOS (.ipa)
  - Requires `.p12` certificate + `.mobileprovision` provisioning profile

## Key Configuration

### Server URL — 编译时默认值 (config.js)
Edit `config.js` to set the default server URL that ships with the app:
```js
export default {
  serverUrl: 'http://192.168.1.56:2026/'  // ← Default when app first opens
}
```

### Server URL — 运行时配置 (应用内修改)
App 启动后，点击右下角的 **⚙ 悬浮按钮** 弹出配置浮层，提供以下功能：

#### 三层 URL 安全防护
1. **格式校验**：实时检查 URL 格式，自动补全 `http://` 协议前缀，拦截空格/中文等非法字符
2. **内网检测**：检测到公网域名（如 baidu.com）时提示用户「DeerFlow 服务器通常位于内网」
3. **服务器身份验证**（硬限制）：点击「测试连接」向 `{serverUrl}/health` 发送 GET 请求，验证返回 `service === "deer-flow-gateway"` 且 `status === "healthy"`，**非 DeerFlow 服务器的 URL 禁止保存**

#### 交互流程
```
⚙ 按钮 → 弹出配置浮层
  → 输入 URL（实时格式校验 + 内网检测）
  → 点击「测试连接」→ GET /health 验证
    ├─ 验证通过 → 绿色 ✓ → 保存按钮启用
    └─ 验证失败 → 红色 ⛔ → 保存按钮禁用
  → 「保存并加载」→ 持久化到本地存储 + WebView 重新加载
  → 「恢复默认地址」→ 恢复 config.js 中的默认值
```

#### 错误提示覆盖层
WebView 加载失败时（网络不可达/服务器无响应/10秒超时），自动显示错误覆盖层：
- ⚠️ 红色图标 + 「无法连接服务器」标题
- 当前 URL 卡片 + 操作按钮
  - 「✏️ 修改服务器地址」→ 打开配置浮层
  - 「🔄 检查网络并重试」→ 重新加载 + 指数退避（2s → 4s → 8s → 15s）
- 网络恢复时自动提示「网络已恢复，点击重试加载」

### HTTP Cleartext (manifest.json)
Since the internal server uses plain HTTP, both platforms must allow cleartext traffic:
- **Android**: `app-plus.distribute.android.manifestPlugins.usesCleartextTraffic: true`
- **iOS**: `NSAppTransportSecurity:NSAllowsArbitraryLoads` set via plistcmds

### App ID
The `appid` in `manifest.json` is auto-generated by HBuilderX on project creation. **Never change it** — it's tied to cloud build certificates.

### Navigation Title Sync (index.vue)
The `@title` event on `<web-view>` syncs the web page's `<title>` to the native navigation bar. No manual title management needed.

### Health API (/health)
DeerFlow 后端提供 `GET /health` 端点，返回 `{"status":"healthy","service":"deer-flow-gateway"}`，用于 App 内的服务器身份验证（硬限制）。如果去掉该端点或修改返回格式，需同步更新 `index.vue` 中的验证逻辑。

## Important Notes
- The actual app source lives under `DeerFlowApp/DeerFlowApp/` (HBuilderX creates a project subdirectory inside the parent folder)
- The server URL is configured via `config.js` — edit it before cloud build if the address changes
- DeerFlow frontend updates are reflected automatically in the app (no rebuild needed)
- No unit tests, no CI/CD — validation is done via device testing
- **URL 硬限制**：通过 `/health` 身份验证是保存 URL 的必需条件，非 DeerFlow 服务器的地址无法保存
